# SecretMask

This project is a next application that does the following.

- Takes in key value pairs of secrets and masks them for secure handling
- Provides an unredacted text input for entering the unredacted text that contains the secrets
- Displays the masked version of the text with the secrets hidden in a second redacted text area
- Allows pasting redacted text to the redacted text area and displays unredacted text in the unredacted text area
- Supports bidirectional masking and unmasking of secrets within the text areas
- Allows saving the key value pairs of secrets for future use so they can be reused without re-entering them
